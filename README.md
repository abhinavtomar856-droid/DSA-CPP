# DSA-CPP

Data Structures and Algorithms practice in C++, organized by topic.

## Topics Covered

- **Basic Maths**: basic number problems and maths logic
- **Loops**: loop practice and pattern printing
- **Arrays**: searching, sorting, insertion, deletion, shifting
- **Binary Search**: binary search and its variations
- **Hashing**: hashing concepts and problems
- **OOPS**: classes, objects, inheritance, polymorphism
- **Pointers**: pointer basics, dynamic memory
- **Structures and Unions**
